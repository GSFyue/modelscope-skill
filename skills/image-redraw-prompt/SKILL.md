# 图片重绘提示词

把参考图转换为可直接执行的重绘提示词。核心不是重新描述图片，而是锁定原图核心结构，用尽量少的文字明确「不变项 + 优化项 + 核心锚点」，让生成模型输出同一画面的更清晰、更稳定、更高完成度版本。

## 使用说明

- 功能：为参考图生成 Midjourney、Seedream、Image 2.5 三个版本的高保真重绘提示词。
- 输入：1 张参考图；可选目标模型、重绘强度、必须保持或必须修改的内容。
- 输出：三个模型版本的重绘提示词、3—6 条主体锚点，以及一句执行说明。
- 示例：用户发来角色设定图并说「高清重绘」，保持构图、主体位置、比例与原风格不变，只提升清晰度、材质、光影和完成度。

## 适用场景

- 重绘、复刻、高清修复、提升画质、优化完成度。
- 保持原图构图、视角、主体与风格，生成可用于图生图的提示词。
- 只改一处细节，例如服装颜色、表情或局部材质。
- 明确要求换风格，例如真人化、CG 化、动漫化、电影感。

不适用：

- 只要求描述图片内容。
- 根据图片做全新创作、扩写世界观或重新设计角色。
- 要求直接生成或编辑图片；本技能只产出提示词。

## 核心原则

1. **重绘 ≠ 反推描述**：不逐项复述画面，不把提示词写成图片分析报告。
2. **保持优先**：先写必须保持不变的内容，再写优化目标，最后写禁止改动。
3. **默认保持原风格**：用户未明确要求换风格时，不擅自电影化、写实化、CG 化或二次元化。
4. **锚点少而准**：只保留 3—6 个防止跑偏的关键锚点。
5. **短而可执行**：优先短提示词，只有原图结构确实复杂时才增加长度。
6. **三版同目标**：Midjourney、Seedream、Image 2.5 必须表达同一个重绘目标，只改变语言和结构。

## 输入检查

开始前确认：

- 参考图是否清晰可读；
- 用户要的是高清重绘、局部修改，还是换风格；
- 是否需要指定 Midjourney 画幅比例；
- 用户是否指定了必须保留或必须修改的元素。

缺失信息按默认模式处理；只有会明显改变结果时才追问一次。

## 执行流程

1. **判断模式**：根据用户措辞选择默认高清重绘、局部修改或风格重构；未说明时使用默认模式。
2. **提取锚点**：从图中选 3—6 个高控制价值信息，按「构图 → 主体身份 → 服装或物体 → 尺度关系 → 独特色块 → 背景结构」排序。
3. **确定优化目标**：只选与当前图片问题相关的项，例如清晰度、材质、光影、结构稳定性、完成度，不堆砌。
4. **构建保持项**：写明构图、视角、主体数量、位置、比例、角色或场景设计、色彩关系与风格方向不变。
5. **生成三版提示词**：按固定结构输出；Midjourney 用高密度英文短句，Seedream 与 Image 2.5 用简洁中文。
6. **自检并压缩**：删除无控制价值的细节、空泛形容词和重复表达，确认三版目标一致。

## 模式判定

### 默认｜原风格高质量重绘

触发词：重绘、复刻、高清重绘、优化一下、提升画质。

- 保持：构图、视角、主体数量与位置、比例、前中后景、角色或场景设计、配色逻辑、原风格方向。
- 优化：清晰度、干净度、结构稳定性、材质、发丝或毛发或布料细节、光影统一性、色彩纯净度、层次、完成度、轻微瑕疵。
- 禁止：改构图、改比例、改镜头、换服装、换场景、增删重要元素、自动改画风。

### 局部修改

用户明确要求改一处内容时：

- 保持：原构图、原镜头、原主体比例、原场景、原风格。
- 只修改用户点名的内容。
- 不因一个局部修改而重做整幅画面。

### 风格重构

仅当用户明确说换风格、真人化、CG 化、动漫化、水墨化、电影化或重新设计时启用。

- 保留用户指定的构图与主体关系。
- 只改变用户指定的风格维度。
- 结构变为：保持项 → 指定修改项 → 优化目标 → 主体锚点 → 新风格质量词。

### 强度分级

- **Level 1 原图高清重绘（默认）**：构图、风格、主体、色彩、设计全部保持，只优化画质、清晰度、材质、光影、细节与瑕疵。
- **Level 2 原风格增强**：保持构图、主体与风格方向，允许强化材质、光线、对比、空气感与完成度，但不重新设计。
- **Level 3 风格重构**：允许改变风格、材质语言、光影方向与视觉表达，但保留用户指定的核心构图与主体。

## 主体锚点规则

- 数量：3—6 条。
- 每条只写一个识别点，不展开成长句。
- 优先级：构图锚点 > 主体身份或类型 > 明显服装或物体 > 关键尺度关系 > 独特色块 > 特殊背景结构。
- 不要复述五官细节、完整服装清单或逐个环境元素。

## 信息优先级与压缩

排序：**不变项 > 优化目标 > 核心视觉锚点 > 风格质量词**。

默认删除：

- 不影响重绘的细枝末节；
- 装饰物逐项罗列；
- 过长的人物五官与服装材质描述；
- 重复的色彩描述；
- 「高级、震撼、唯美、梦幻」等空词；
- 同义反复。

长度建议：

- Midjourney：约 80—180 个英文词。
- Seedream：约 120—250 个中文字。
- Image 2.5：约 100—220 个中文字。

## 输出格式

直接输出以下结构，不写长篇视觉分析：

```markdown
# 图片重绘提示词

**执行说明**：一句话说明本次模式、保持重点与优化重点。

## 1｜Midjourney

> faithful redraw of the reference image, ... --ar X:X --style raw

## 2｜Seedream

**重绘指令：** 严格参考原图重绘，保持……

**优化目标：** 提升……

**主体锚点：** 锚点 1；锚点 2；……（3—6 条）

**风格质量：** 保持原风格，……

## 3｜Image 2.5

> 根据参考图进行高一致度重绘。保持……
```

要求：

- 三版必须表达同一个重绘目标。
- Midjourney 保持短、高密度，默认只带 `--ar` 与 `--style raw`；用户使用图片参考且需要更强一致性时再加 `--iw`。
- 未知画幅比例时先询问，或按原图比例填写；不要编造。
- 默认不输出视觉分析、评分或额外的创意建议。

## 输出前自检

- [ ] 明确写了保持构图、视角、主体位置与比例；
- [ ] 明确写了本次优化目标；
- [ ] 默认保持原风格，没有擅自改造画风；
- [ ] 主体锚点 3—6 条，没有展开成长段；
- [ ] 没有把图片重新完整描述一遍；
- [ ] 没有堆砌空泛质量词或重复内容；
- [ ] Midjourney 足够短，Seedream 以执行指令为主，Image 2.5 自然简洁；
- [ ] 三版表达同一个重绘目标。

## 详细模板与词库

需要完整模板、示例、优化词库和风格改变写法时，读取 `reference.md`。

## 安全与边界

- 不声称已生成或修改图片，只输出提示词。
- 不编造参考图中不存在的主体、文字或细节。
- 不根据一张图推断真实人物身份。
- 涉及真人肖像、商标或受版权保护角色时，提醒用户自行确认使用权限。
- 用户要求完全复刻受保护作品时，改为「保持构图与风格的原创重绘」表述，并提示版权风险。
